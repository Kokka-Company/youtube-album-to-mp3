# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be respectful and assume good faith. Criticise code, not people.
- No harassment, insults, sexualised language or imagery, or publishing anyone's
  private information.
- Stay on topic. Issues and pull requests are for this project.

Maintainers may edit or remove comments, commits, issues and pull requests that
break these rules, and may block repeat offenders.

## Reporting

Contact the maintainers through [kokkaco.com](https://kokkaco.com). Reports are
kept confidential. The full Contributor Covenant text linked above sets out how
reports are handled and the possible outcomes.
